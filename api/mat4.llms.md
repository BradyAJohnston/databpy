# mat4

``` python
mat4()
```

A `FLOAT4X4` attribute: a row-major 4x4 float32 matrix per element.

## Methods

| Name | Description |
|----|----|
| [fill](#databpy.mat4.fill) | Fill the array with a scalar value and sync to Blender. |
| [partition](#databpy.mat4.partition) | Partition the array in-place and sync to Blender. |
| [put](#databpy.mat4.put) | Set values at the given flat indices and sync to Blender. |
| [sort](#databpy.mat4.sort) | Sort the array in-place and sync to Blender. |
