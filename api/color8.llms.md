# color8

``` python
color8()
```

A `BYTE_COLOR` attribute: an sRGB RGBA uint8 color per element.

Hex codes such as ‘#FF8000’, or a list of them, can be wrapped as well.

## Methods

| Name | Description |
|----|----|
| [fill](#databpy.color8.fill) | Fill the array with a scalar value and sync to Blender. |
| [partition](#databpy.color8.partition) | Partition the array in-place and sync to Blender. |
| [put](#databpy.color8.put) | Set values at the given flat indices and sync to Blender. |
| [sort](#databpy.color8.sort) | Sort the array in-place and sync to Blender. |
