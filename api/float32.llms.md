# float32

``` python
float32()
```

A `FLOAT` attribute: one float32 value per element.

## Methods

| Name | Description |
|----|----|
| [fill](#databpy.float32.fill) | Fill the array with a scalar value and sync to Blender. |
| [partition](#databpy.float32.partition) | Partition the array in-place and sync to Blender. |
| [put](#databpy.float32.put) | Set values at the given flat indices and sync to Blender. |
| [sort](#databpy.float32.sort) | Sort the array in-place and sync to Blender. |
